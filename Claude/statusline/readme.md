# Claude Code statusline 
### Mac 설정
다른 Windows PC에서는 파일 3개를 그대로 복사하면 되고, 경로 수정이 필요 없습니다.

|  파일  | 수정 필요 |
|-- |--|
| ~\.claude\statusline-command.sh   | 없음  |
| ~\.claude\subagent-statusline.sh   | 없음  |
|~\.claude\settings.json 의 statusLine 블록 | 없음 |

### Windows 설정  
다른 Windows PC에서는 파일 2개를 그대로 복사하면 되고, 경로 수정이 필요 없습니다.

|  파일  | 수정 필요 |
|-- |--|
| ~\.claude\statusline.ps1   | 없음 (non-ASCII 0바이트, 인코딩 무관) |
|~\.claude\settings.json 의 statusLine 블록 | 없음 |
